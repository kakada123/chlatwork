ChlatWork Grammar

Use your existing ChlatWork AI grammar API. No new Gemini key or separate AI server needed.

Endpoint on your ChlatWork backend (e.g. http://localhost:3002/creator-ai/grammar/correct or http://localhost:3002/creator-ai/khmer/grammar). It reuses your existing Gemini grammar service.

For local testing only. Held in session memory and cleared when the browser restarts, extension reloads, or is updated. Never paste your Google Gemini key here.

How to use

  1. Connect the API above.
  2. Open any regular website with a text field.
  3. Write text and click ✨ Fix grammar.
  4. Review the correction, then Apply or Copy.

Only text you explicitly submit is sent. Do not use with passwords, private customer data, or confidential work content.
